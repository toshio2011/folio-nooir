# ✨ What's new in Folio Nooir v1.6.7 📖

SOOO… remember when I said I was just going to fix a few things? HAHAHA. 🤣

Somehow that turned into *another* update, plenty of memory debugging, and a lot of Bluetooth testing. This time I've been focusing on something simple: **letting Nooir get on with reading, while making Bluetooth page turning much more usable on the original X4.**

There are some lovely little improvements elsewhere too. As always, this is me sharing what I've been tinkering with — not a promise that every device and every book will behave perfectly. 💜

## 🕹️ Bluetooth page turning — the big one!

- **Adaptive EPUB BLE:** Nooir can temporarily stop Bluetooth *before* memory-hungry rendering, keep the captured page-turn command, finish drawing the page, and try to reconnect when it's safe.
- **Automatic return:** The post-render memory cleanup and BLE readmission can happen again during the same EPUB reading session instead of getting stuck after the first turn.
- **Controller improvements:** Generic HID input learning, IINE support, saved mapping profiles, clearer status feedback, and Device Info diagnostics.
- **Reader first:** BLE still yields memory to EPUB rendering rather than risking the book, and XTC's BLE path is retained when resources allow.

The earlier experimental `_04` firmware completed repeated page turns, suspension and reconnection on my original X4. That was such a relief after all the tinkering! 😂 **The actual official 1.6.7 download is a separate clean-label build and has not itself been flashed or physically smoke-tested**, so Bluetooth is still experimental.

## 📖 Reader, memory & SD-card improvements

- Improved EPUB section handling, safe temporary-memory recovery, and rendering-aware BLE coordination.
- Refined reading progress/state persistence and recovery paths.
- **SPI-array SD transfer acceleration** on the original X4, with a byte-mode fallback retained in source for compatibility.
- Kept EPUB styling, fonts, images, tables, RTL and familiar Reader controls intact.
- XTC/XTCH and CBZ reading paths remain available; they aren't being replaced or redesigned here.

The goal isn't to add background work for the sake of it. It's to keep the reading experience responsive even as the firmware grows.

## 📚 Bookshelf, statistics & Settings

- Improved Recent/Finished shelf progress and completion-state consistency.
- Refined Main/Lite bookshelf behavior and reviewed UI fixes.
- Expanded the achievements collection to **30 achievements**, using existing reading statistics.
- More usable BLE mapping/profile screens, plus Device Info and status feedback.
- Existing Clock & Weather behavior remains available.

The original Folio Nooir feel is still here. And yes, Folio Lite is staying too! 🤭

## ⚠️ Before installing

**This download is for the original XTEINK X4 (ESP32-C3) only.** Please don't flash it on X3, X4 Classic, X4 Pro, or other S3 hardware. Although the X3 source path is retained, no X3 firmware is included or physically validated in this release.

Please back up your current firmware and reading data, and keep a recovery method available. You can use the repository's CrossPoint web-flashing instructions, or put the release asset named `firmware.bin` at the SD-card root and use the device's firmware update screen.

**What's still on the list?** The no-device Interrupt-WDT and partial NimBLE initialization rollback need more work. The exact official image hasn't completed the 20-turn single-session, backward-turn, XTCH, BLE-OFF performance, complex EPUB, sleep/wake or long-duration hardware tests. BLE may still stop on demanding pages to protect reading.

## 📱 A little side project — MihonNooir!

Meanwhile, my other tinkering project somehow grew too. HAHAHA. 🤣

[MihonNooir v1.0.19 — Smarter Manga Reading](https://github.com/toshio2011/mihon-nooir/releases/tag/v1.0.19) is the latest **Android** release. It's a separate optional Mihon-based companion for preparing manga chapters for e-readers.

This release improves tricky panel layouts and adds **Enlarge oversized splits** (default 50% screen fill), alongside Panel by Panel, Row by Row, previews and export options such as XTC/XTCH and CBZ. The Windows version is still in development.

You don't need MihonNooir to use Folio Nooir. It's just another little project I've enjoyed sharing. 📚
